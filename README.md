🛍️ Native Shop App

A full-stack shopping application designed to provide a simple and modern e-commerce experience. The project is built with a separate mobile frontend, backend, and admin side, making it easier to manage and extend as the application grows.

🚀 About the Project

Native Shop App is an e-commerce project where users can browse products and interact with the shopping platform through the mobile application.

The project is structured into three main parts:

📱 Mobile — User-facing shopping application
⚙️ Backend — Handles the application's server-side logic and APIs
🛠️ Admin — Provides functionality for managing the shopping platform
